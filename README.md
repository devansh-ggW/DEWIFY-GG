# DEWIFY-GG

DEWIFY's digital-products storefront.

This repo intentionally contains only the storefront theme and lightweight front-end behavior. The previous physical-product catalogue, Google Sheets/App Script order flow, shipping/address checkout, supplier integrations, admin order system, and demo products are not included.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages compatible

The digital catalogue is currently empty and ready for future product releases.
