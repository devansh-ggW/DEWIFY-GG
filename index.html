NEED TO KNOW

Questions, answered.

What does DEWIFY sell?+

DEWIFY sells digital products, software, web tools and games.

Who is behind DEWIFY?+

DEWIFY is a digital-products brand operating under DwarfX.

What is DevCore?+

DevCore is DEWIFY's desktop developer environment and the first PC software release listed on the store.

What is Ascend Automation?+

Ascend Automation is an Android automation tool that lets users create keyword-based rules for supported notification replies.

What is DwarfX Converters?+

DwarfX Converters is a browser-based utility suite for common image, data and text conversion tasks. Processing is performed locally in the browser.

Does DEWIFY have games yet?+

The Games library is being structured for both 2D and 3D releases, with genre categories ready for future titles.

Why does Ascend need Notification Access?+

Notification Access lets Ascend receive the notification content needed to match rules and use supported reply actions. Users should only enable it if they understand and trust the automation they configured.

How does delivery work?+

Digital software is delivered online through a download link after purchase or from the product page where available.
